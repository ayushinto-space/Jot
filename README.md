# ✍️ Jot — Modern Minimalist Publishing Platform

Jot is a lightweight, distraction-free blogging and publishing platform built with Next.js App Router, Tiptap, Tailwind CSS, and Supabase. Designed for high readability and lightning-fast publishing at the speed of thought.

---

## ✨ Features

- **⚡ Fast Next.js App Router Setup**: Built with server components for optimized performance and SEO.
- **🎨 Minimalist Light Mode Theme**: Clean typography, crisp headings, and structured editorial layout.
- **📝 Tiptap Rich Text Editor**: Intuitive editor outputting clean HTML strings for reliable rendering.
- **🖼️ Hero Cover Image Support**: Upload or link high-resolution cover photos for articles.
- **📂 Clean Route Structure**: Dynamic `[slug]` pages for permanent article URLs.
- **🧹 Sanitized Card Feed**: Automatic HTML tag stripping for clean, multi-line post previews on the home feed.
- **🗄️ Supabase Database Integration**: Instant persistent storage powered by Postgres.

---

## 🚀 Tech Stack

- **Framework**: [Next.js 15+](https://nextjs.org/) (App Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Rich Text Editor**: [Tiptap](https://tiptap.dev/)
- **Database**: [Supabase](https://supabase.com/) (PostgreSQL)
- **Icons & UI**: [Lucide React](https://lucide.dev/)
